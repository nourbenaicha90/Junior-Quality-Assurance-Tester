## Project 1 — REST API Testing with Postman

A practice collection using the public JSONPlaceholder test API (`https://jsonplaceholder.typicode.com`). This is a public demo service, not a production system.

### Scenarios covered
- Retrieve a post and verify HTTP 200 and JSON fields.
- Retrieve a non-existing resource and verify the response.
- Create a post and validate the returned payload.
- Update a post and validate the response.
- Delete a post and validate the response.

### How to run
1. Install Postman.
2. Import `postman/JSONPlaceholder_API_Testing.postman_collection.json`.
3. Run the collection using Collection Runner.
4. Review each request's **Tests** tab and the run results.
5. Save your own screenshots and actual run date under `evidence/` (do not claim results until you have run it).

## QA Approach

1. Understand the requirement and identify risks.
2. Define test scenarios and expected results.
3. Prepare test data and environment.
4. Execute tests and record actual results.
5. Report defects with clear reproduction steps and evidence.
6. Retest fixes and perform focused regression testing.
7. Summarise coverage, results, limitations and open risks.
